# Contributing to Awesome Competitive Pokémon

Thank you for helping maintain this resource list. This guide explains how to contribute effectively.

---

## What Makes a Good Addition?

Before submitting a pull request, ask yourself:

1. **Is it publicly accessible?** No paywalls, login walls, or download-only resources.
2. **Is it maintained or archived?** Links should resolve. If a project is archived but still valuable (e.g., reference implementations), note it explicitly.
3. **Is it directly useful for competitive play or development?** Casual guides, trading posts, or unrelated tools don't fit here.
4. **Is it evergreen?** Prefer resources that remain useful across multiple generations or seasons. Time-sensitive content (e.g., a specific Regulation's meta) should be clearly dated.
5. **Is it duplicative?** If a similar resource already exists in the list, explain why your addition adds distinct value.

---

## How to Submit

### Adding a Resource

1. Fork this repository.
2. Add your resource to the appropriate section in `README.md`.
3. Use this table row format:

```markdown
| [Resource Name](https://url) | One-sentence description of what it does | Format/Language |
```

4. If no appropriate section exists, propose a new one in your PR description.
5. Submit a Pull Request with the title format: `Add: [Resource Name]`

### Fixing a Broken Link

1. Open an Issue with the title `Broken link: [Resource Name]`.
2. Include the current (broken) URL and the corrected URL if known.
3. Or submit a PR directly with the fix.

### Suggesting a New Section

Open an Issue with the label `enhancement` and describe:
- What the new section would cover
- At least 3 resources that would belong in it
- Why it's distinct from existing sections

---

## Style Guidelines

- **Descriptions** should be one sentence, objective, and free of superlatives ("the best", "amazing", etc.).
- **Links** should point to the most stable URL (e.g., GitHub repo root rather than a specific commit).
- **Tables** should be used for structured resource lists; bullet points for prose references.
- **Code blocks** should use appropriate language identifiers (` ```python `, ` ```bash `, etc.).
- Do not self-promote or add resources solely to advertise a service. Community trust depends on neutral curation.

---

## What We Don't Accept

- Resources behind paywalls or requiring account creation to access core content.
- Links that are primarily advertisements or affiliate links.
- Resources with no clear relevance to competitive Pokémon (VGC, Smogon, or battle mechanics).
- Duplicate entries covering the same ground as existing resources.
- Resources that are clearly abandoned with no archival value.

---

## Reporting Issues

Use GitHub Issues for:
- Broken or redirected links
- Outdated information in descriptions
- Missing important categories
- Resources that no longer meet quality criteria

---

## Maintenance Schedule

This list is reviewed and updated approximately **2–4 times per year**, typically aligned with:
- New Pokémon generation releases
- Major VGC Regulation changes
- Annual review pass (broken links, new notable tools)

If you notice the list is drifting out of date, opening an issue with `[Maintenance]` in the title is the most helpful action.

---

## Code of Conduct

Be respectful in all interactions. This is a technical resource repository, not a discussion forum. Keep contributions focused on the content, not on interpersonal disagreements.
